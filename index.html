About these reports

Each report above is a merged Playwright HTML report generated in GitHub Actions and published here via GitHub Pages -- no AWS involved. Reports are regenerated on every matching workflow run, so the links always show the latest result for that suite.

  • Main: fast confidence check on the exact commit that's about to deploy.
  • Weekly: the expensive full cross-browser + visual + accessibility sweep, kept infrequent to save CI minutes.
  • Production smoke: only @production-safe tests, against the real live site, right after a real deploy.
